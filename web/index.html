How Replore works

  
Three steps, right in your browser — no account, no key.

  

  
  
Describe your project, tap Find, and get the repos that fit — relevant, popular, free to use.

  
For AI-written searches, a relevance check, and a whole PRD read feature
    by feature, use the Claude Code plugin.






  
  
Use Replore in Claude Code

  
New to this? Do these once. The plugin writes smarter searches with AI, checks each result
    actually fits, reads a whole PRD feature by feature, and shows every suitable repo — not just 10. Free & open-source.

  
    
    
  1. Get Claude Code — a free AI coding assistant that runs in your terminal. Install it from
      claude.com/claude-code and sign in.
    2. 
    
  2. Check Python 3.11+ — in your terminal, run python3 --version. If it's missing: on Windows
      install from python.org (tick "Add python.exe to PATH"); on a Mac run brew install python.
    3. 
    
  3. Open Claude Code in any folder — type claude in your terminal and press Enter.
    4. 
    
  4. Add the plugin — paste each line and press Enter:
      
    /plugin marketplace add chittychat-studio/replore
/plugin install replore@replore
    5. 
    
  5. Find repos — describe what you're building in plain words:
      
    /replore:find a diet app for iPhone, starting from scratch
    6. 
    
  6. Read the results — you get a table: the repo, how popular it is (stars), whether it's free to use
      in a paid product, and why it fits. Pick one and start building.

About the results

  
Results are ranked by fit — how well a repo matches your words, how popular it is (stars),
    and how freely you can use its license — so the top pick is relevant and popular and free to use,
    not just the most-starred. Each card says why it's relevant. The
    Claude Code plugin
    goes further: it writes smarter searches with AI, runs a semantic relevance check, and reads a whole plan
    feature by feature. Results are GitHub search matches, not a scan of every repository. Stars measure
    popularity, not quality, and can be bought. "Completely free?" and "OK in a paid product?" are read from the
    license only — a plain summary, not legal advice; some projects also sell a paid hosted version or add-ons.
