Use in Claude Code (full version)

The plugin writes smarter searches with AI, runs a relevance check, reads a whole PRD, and shows every suitable repo — not just 10. Free & open-source (MIT).

/plugin marketplace add chittychat-studio/find-repo
/plugin install find-repo@find-repo
/find-repo:find <what you are building>

Needs Claude Code and Python 3.11+. Full guide: github.com/chittychat-studio/find-repo.

About the results

The browser version does basic keyword search; the Claude Code plugin writes better searches and runs a relevance check. Results are GitHub search matches, not a scan of every repository. Stars measure popularity, not quality, and can be bought. "Completely free?" and "OK in a paid product?" are read from the license only — a plain summary, not legal advice; some projects also sell a paid hosted version or add-ons.
